# neygodnik.ru

Сайт личного блога «Неугодник» (Аслан). Статичный сайт на GitHub Pages, домен neygodnik.ru.

## Как устроено

- `_data/posts.json`: все посты (id = номер поста в t.me/neygodnik, дата, заголовок, адрес, рубрика, текст в HTML, фото).
- `_data/library.md`: каталог «Библиотеки Товарища».
- `_tools/build.py`: собирает весь сайт из `_data/` в корень репозитория.
- `_tools/import_tg.py`: импорт новых постов из выгрузки канала (существующие записи не трогает).
- `assets/style.css`: оформление. `img/posts/`: картинки постов.

## Новый пост

1. Добавить запись в `_data/posts.json` (или импортировать из выгрузки канала).
2. `python3 _tools/build.py`
3. Закоммитить и отправить в `main`. Через минуту-две сайт обновится.

Рубрики и серии задаются в начале `_tools/build.py` (`RUBRICS`, `SERIES`).
